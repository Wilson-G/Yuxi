# 专家项目 Prompt 设计师

这是专家学习第 0 阶段的中央方法。它采用参考项目已经验证过的“编译简报 + 单篇来源合同 + 独立验活 Review + 主题手艺册”方案，再适配 Yuxi 的项目阶段和响应合同。它不是给每个项目套同一组角色卡，也不是把材料变成摘要、目录或审计档案。

最终目标是让后续模型从材料中学到两种东西：

- 可迁移的判断手艺：遇到什么局面，先看什么信号，怎样取舍，为什么这样做，什么条件会改变或停止判断；
- 材料中特有的术语、口诀、公式、经验口径、特殊关系、取用法和断语：按作者原意、含义和已说明的条件保留下来，不以外部共识筛掉。

单篇笔记是给主题阶段使用的来源语义载荷。它不是最终讲义、案例复述、学徒思考记录、主题分类表或 Review 台账。主题阶段才负责跨材料合并，讲义阶段才负责教材化地写成手艺册。整套交付称为项目专属 Prompt 包，不是材料审计报告。

中心层要求所有项目先按同一个抽象方向生成专属 Prompt：

```text
材料结构/信号 -> 作者如何把它转成判断或表现 -> 这条转换的适用条件与边界
```

这里的“作者”是当前材料中实际传授判断的人。阶段 Prompt 统一使用“作者”“材料中的作者”或项目已经声明的通用角色，不把项目名、作者姓名、UP 主名或人物名写进通用身份。领域术语可以保留，专名不是学习合同的一部分。

## 项目定向

第 0 阶段只决定“这批材料应该怎样学”，不提前学完全部材料。

先读材料目录、项目说明和用户确认的代表材料。调研要确认：

- 材料属于什么领域，传授的是何种判断或操作手艺；
- 材料形态是口述、对话、课堂问答、案例、教程、访谈还是书面说明；
- 说话人结构如何区分，学生或访谈者的提问、反馈和转写噪音怎样与作者口径区分；
- 材料真正值得继承的是判断顺序、条件化决策、公式、经验边界、专属知识还是其他手艺；
- 多来源差异是否会改变同一判断；只有会改变时才保留来源差异；
- 截断、转写、资料缺口或案例限制是否改变结论强度或可用范围；
- 最终专家需要怎样的领域基础、判断姿态和边界表达。

项目定向报告只用于形成项目专属编译底稿，不是单篇笔记或理论百科。有限样本不能变成后续每份材料的固定概念清单。

## 编译底稿

完整结构示例见 `examples/apprentice-stage-prompt-pack.md`；它只展示结构，不携带领域内容。

项目专属编译底稿必须写清：

- 最终专家继承哪种材料内的判断传统；
- 学徒和独立同门已经具备哪些领域基础，本轮不重复解释什么；
- 材料的语体、说话人结构和转写纪律；作者纠正前后以哪一段为准；
- Author 怎样完整阅读一份自然材料并提炼来源支持的判断；
- Reviewer 怎样独立复读原文、建立内部知识账本并只报告真正阻断下游使用的问题；
- 多篇笔记怎样按读者局面形成主题，怎样保留冲突和分型；
- 讲义怎样成为可练习的手艺册，最终 Skill 怎样带着专家姿态回答问题。

底稿必须要求单篇学习把每个候选判断拆成三层：

1. 材料中作者实际看见的结构、关系、信号或条件；
2. 作者把它转成了什么语义、表现、取法或结果，以及材料给出的理由、代价或作用链；
3. 这条转换能在哪类相近局面使用，什么条件会改变它；材料只支持本案时，明确保留本案边界，不冒充通用规律。

底稿和阶段 Prompt 应使用当前领域的自然语言，不写成机器协议、文件操作说明或流程身份表。项目学习方案会直接交给单篇学习、Review 和修订任务，因此只能说明共同的学习深度和方向，不得把样本中的具体术语、案例类型或预设课程顺序变成逐篇检查清单。

## 单篇 Author 合同

每份自然材料必须完整阅读。Author 是正在向材料中的作者学判断的同领域学徒，不是摘要员，也不是替后续编辑交付目录的人。

内部复盘时先辨认材料形态和说话人，再找作者实际观察的结构、信号、优先取舍、明说理由、误判或替代做法、条件、例外、反转和停止线。对话材料中不得把学生的问题当成作者的判断；口头禅、重复和明显转写噪音不是知识；作者后续纠正的说法覆盖前面的误说。

正文只保留少量可直接使用的判断句，优先写成：

```text
结构/信号 -> 作者的转换口径或判断 -> 适用条件、证据强度或改变结论的条件
```

不要只写“本例发生了什么”。如果作者把某种结构解释成作品、名利、关系、风险或行为表现，要写清结构如何转成该语义；材料只支持本案时，明确保留本案边界。

如果材料明确给出机制、代价、固定顺序、数字、阈值、公式、动作方法或方式语义，它们属于判断本身；不能因想压短而删掉。能把具体对象换成变量而不越过材料支持时，保留一层一般形式；材料只支持半步时，保留半截缺口，不补成完整理论。作者只给口诀、公式、顺序或经验口径时，如实保留并标明已说明的适用范围。

`note_markdown` 只能写自然 Markdown，不能输出 JSON、JSONL、对象、字段名、知识单元数组或内嵌 evidence。案例背景、人物事件、逐步推演、原文行号、审稿说明和学徒内心活动不进入正文；行号和支撑说明只进入现有响应合同的 `evidence`。明确提出的专属知识不能因只出现一次、不能由普通推理推出或无法外部证明而删除。

`routing_labels` 是来源级语义路标，不是主题或结论。优先使用三种形式：`见某信号，判什么`、`同一表象：是 A 还是 B`、`要做某事时，先看什么`。禁止只有“婚姻”“事业”“大运”这类空类目；标签只复述材料展示的信号、取舍或先看项，不补因果或反向路径。

## 单篇 Reviewer 合同

Reviewer 是具备项目声明的领域基础、熟悉同一判断传统的独立同门。先完整读原文，再完整读当前笔记；内部逐段建立本篇所有会改变下游使用的知识账本，完成后一次性核对，不把本轮本可发现的遗漏留给下一次复审。发现一个 blocker 不能停止扫描；必须读到原文末尾，收齐所有实质问题后才给 verdict。后续复审不得补报本轮原文中已经可见的遗漏。

检查：

- 作者的判断、结构到语义的转换、理由、代价、条件、例外、反转和停止信号是否遗漏或被改写；
- 术语、口诀、公式、经验口径、特殊关系和取用法是否保留原意及条件；
- 具体案例是否被误写成无条件通则，或外部理论被伪装成作者口径；
- 数字、阈值、真实顺序、动作优先级、方式语义和证据强度是否改变；
- 变量化的一般形式是否超出材料支持；
- 是否只摘录了案例结论，却没有保留作者从结构到结论的转换关系；
- 每个 `evidence.supports` 是否真的支撑对应判断；
- 路标是否反转、夸大、遮住核心判断或退化成空类目。

不得用外部共识、普通常识或“能否普遍证明”否定材料中明确的作者口径；也不得要求每篇材料都有固定步骤。只输出通过结论，或按严重程度列出会影响后续学习、合成或使用的具体问题及修订方向。知识账本、审稿过程、泛泛标准和不影响下游的措辞意见不输出。

## 主题与讲义合同

主题按读者真实局面切，不按人物、文件标题、百科类目或材料顺序切。候选研究先用路标召回可能相近的笔记，再完整阅读笔记决定哪些判断能共同教学、哪些条件必须分开、哪些冲突不能统一。标签只用于召回，不决定最终主题。

讲义是浓缩的手艺册，不是笔记拼接或证据档案。结构优先采用：

1. 一句话说明本门解决的局面和何时启用；
2. 按“结构/条件 -> 作者的转换判断 -> 使用边界”排列的判断主干；
3. 材料确实支持时，按关系、作用方式、位置、介质或其他领域轴做家族分型，并写清各类从结构到语义的迁移方向；
4. 案例只作为类内短例和支撑，不能平铺替代方法；
5. 证据退居判断之后，不把正文写成逐段审计。

只保留当前材料实际支持的先看项、机制、作者口径、条件和分叉，不预设每篇都要经过资料、原局、取用、运年等固定流程。材料不足以形成统一分型时保留差异，不为了整齐强行分类。

讲义 Reviewer 只报告会令读者学错判断的实质问题。若已通过笔记支持明确同族关系，而讲义仍平铺案例、没有材料支持的分型轴或迁移方向，要求修订；仅因措辞偏好不阻断交接。

## 全书、导航和最终 Skill

全书收口只检查跨讲义的术语、边界、冲突、重复、缺口和证据一致性；它返回 Review 合同要求的通过或具体问题，不重写整本书。导航按读者局面进入讲义，不按人物或文件名堆索引。最终 Skill 继承材料确认过的专家姿态、判断主干、专属知识和停止边界，不新增讲义没有的规则。

## 真实小样验收

可用材料不足 4 份时全部试跑；达到 4 份后，选择 4～5 份覆盖不同材料形态或判断方式的代表材料，并发运行“学艺笔记 -> 独立 Review”。检查输出是否真的像在学习这批材料，而不是套领域百科或通用工作流。

- 是否分清作者判断、学生提问、反馈和转写噪音；
- 是否保留机制、方式语义、公式、顺序、条件、反转和专属知识；
- 是否写成少量直接可用的判断，而不是案例过程或学徒思考；
- Reviewer 是否只报告实质 blocker，不把外部共识或文风偏好当门禁；
- 讲义是否有判断主干和材料支持的分型，而不是案例目录。

不贴合时只修改项目编译底稿和阶段 Prompt，再用真实小样验证。用户确认后，当前项目方法版本连同学习方案、底稿和项目专属 Prompt 包一起固定。

## 必守边界

- 不用有限样本预设后续材料的术语、步骤、案例类型或主题；
- 不把个案升级为无条件领域通则，也不因外部不可证明而删除作者专属知识；
- 不把案例、审稿、来源管理或流程交接写进知识正文；
- 不让最终 Skill 退化成百科、搜索器或材料目录；
- 不把材料没有说明的机制、步骤、阈值或分类补进去。
