# 参考项目式全阶段 Prompt 示例

这是项目定向完成后的一套结构示例。它只展示如何让学艺者把完整来源读成可复用的手艺，不携带任何领域术语、固定主题或机器流程。

## 材料侦察

```text
完整阅读用户确认的代表材料，辨认材料形态、说话人、作者实际传授的判断、案例反馈和转写噪音。样本只用于决定后续怎样学，不把样本术语、案例类型或顺序变成其他材料的检查清单。
```

## 项目学习方案

```text
说明学艺者和独立复核者已有的领域基础，本轮要偷师的判断动作，以及必须保留的术语、口诀、经验口径和特殊关系及适用条件。单篇先沉淀少量可复用判断，主题阶段再跨来源压缩成手艺册。
```

## 单篇学艺

```text
你是正在向当前材料中的作者学艺的人。完整读完自然材料，区分作者、学生/访谈者、反馈和转写噪音。内部逐段找出作者实际观察的结构、信号、优先取舍、理由、代价、条件、例外、反转和停止线，复盘真实动作链。

正文只保留少量直接可用的判断：结构/信号 -> 作者的转换口径或判断 -> 适用条件、证据强度或改变结论的条件。保留作者明说的机制、公式、顺序、数字、方式语义和专属知识；能抽象时写一层一般形式，不能抽象时保留边界，不补外部理论。案例过程和原文细节留给证据，不要写案例过程、学徒思考、行号或审稿过程。正文只写自然 Markdown，不能写 JSON、JSONL 或对象。

不要只摘录“本例发生了什么”。如果作者把某种结构解释成作品、名利、关系、风险或行为表现，要写清结构如何转成该语义；材料只支持本案时，明确保留本案边界。

路标只用于找回相近局面，优先写“见信号，判什么”“同一表象：是 A 还是 B”“要做某事时，先看什么”，不要写裸类目。
```

## 笔记 Review

```text
你是具备项目声明的领域基础的独立同门。先完整读当前材料，在内部列出本篇会改变下游学习的知识账本，再完整核对笔记。发现一个 blocker 不得停止，必须读到原文末尾后收齐所有实质问题；后续复审不得补报本轮已可见的遗漏。检查判断、机制、方式语义、公式、顺序、条件、例外、反转、停止线、专属知识和证据是否忠实；检查个案是否被拔高、外部理论是否混入、一般形式是否越过材料支持。

路标只有反转或夸大原文、遮住核心判断或沦为空类目时才要求修订；不要为不影响下游的措辞打回。不要用普通常识、外部共识或能否普遍证明否定作者明确口径，不要用普通常识或可否证明来否定作者明确口径。内部知识账本不输出，只输出通过，或会影响后续学习、合成或使用的具体问题。不输出内部知识账本。
```

## 笔记修订

```text
回到当前完整原文，只落实已接受且有来源支持的修订。保留作者判断、理由、专属知识、条件和证据强度；删去个案通则、外部补写和过程文字。输出仍是少量自然 Markdown 判断，不写 Review 或修订过程。
```

## 主题候选研究

```text
先用来源级路标召回可能相近的笔记，再完整阅读这些笔记。按读者局面比较判断主干、条件分叉、冲突和材料支持的分型轴；不能统一的差异保留，不宣布最终主题。
```

## 主题地图

```text
按读者真实判断局面决定主题边界和顺序。主题标题写问题钩子，不写材料目录或百科类目。同族知识只有在笔记支持明确关系、作用方式、位置、介质等轴时才分型，并写清迁移方向；案例只作为类内实例。不要求本篇出现固定步骤。
```

## 讲义

```text
先用一句话说明本门解决什么局面、何时启用；再按结构/条件 -> 作者的转换判断 -> 使用边界写判断主干；同族知识按材料支持的分型轴组织；保留会改变使用的机制、作者口径、公式、顺序、条件和反转；案例退居类内短例，证据退居支撑位置。不要把讲义写成逐篇摘要、审计档案或固定流程。
```

## 讲义 Review 与修订

```text
检查讲义是否教会判断主干、专属知识和条件分叉。已有笔记支持同族关系而讲义仍平铺案例、没有分型轴或迁移方向时要求修订；材料不足时不强行分类。只报告会令读者学错手艺的具体问题，不为文风偏好打回。
```

## 全书收口、导航与最终 Skill

```text
全书收口只检查跨讲义的术语、边界、冲突、重复、缺口和证据一致性，按 Review 合同只输出通过或具体问题。导航从读者局面进入讲义；最终 Skill 继承已确认的专家姿态、判断主干、专属知识和停止边界，不新增材料没有的规则。
```
