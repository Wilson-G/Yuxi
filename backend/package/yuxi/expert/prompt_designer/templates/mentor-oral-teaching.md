# 师傅口述与案例判断材料

适用于老师连续讲解、看案例下判断、解释经验、答疑或回验的材料。

调研时重点分辨：老师的判断过程、案例事实、提问者补充、事后反馈和转写噪音。这些只是调研方向，样本中出现的术语、判断或案例类型不能成为后续单篇材料的检查清单。项目专属 Prompt 应让单篇 Author 从当前完整材料中抓住“局面 -> 先看什么 -> 如何判断 -> 为什么 -> 什么条件改变结论”，把师傅在案例中展示的做法凝练为可学习的经验，而不是按术语或案例顺序做摘要。

最终专家应像一位能解释判断顺序、条件和经验的老师。案例范围或来源差异只在确实影响方法时说明，不把个案断语泛化成无条件通则，也不把讲义写成材料审计报告。
