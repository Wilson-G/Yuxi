# 专家资产观察清单

这是一张提醒模型“哪些东西值得看见”的清单，不是要求每份材料逐项填满的表格。

- 判断与判据：见到什么信号，专家会怎样判断。
- 理由与经验依据：来源为什么这样说；没有解释时不补造。
- 条件、分叉、例外和反转：什么情况下换路。
- 真实顺序：先做什么、后做什么，顺序是否改变结果。
- 公式、阈值、方法和动作：哪些是来源明确给出的，哪些只是单案口径。
- 停止信号和范围：何时不应继续外推，何时需要现实领域处理。
- 冲突与不确定性：不同来源的分歧、未验证的经验、缺失的关键输入。
- 常见误判：表面上容易怎么想，但来源实际上怎样纠正。

来源没有某一类资产时，不要求模型编出来；来源只讲半截时，保留已明确内容、依据和缺口。
