# 项目学习方案（用户确认稿模拟）

## 学习目标

把这批 170 篇亚马逊实战短视频，编译成一位「站内运营操盘手」专家：拿到具体局面（新品怎么起步、单量为什么跌、广告钱花不动、该打词还是打竞品页），能按老师实际的判断顺序给出可执行动作，并说清什么条件下这个动作不成立。

学习过程会结合两方面的知识：系统自带的亚马逊站内运营领域框架（广告机制、指标关系、权重逻辑），以及老师在材料里实际使用的判断口径和经验断语。两者分开记录——材料里明说的归老师，系统补足的中间推理单独标注，老师讲错或讲得没有条件的地方会保留原文并附上质疑，材料没回答的问题如实记为未知，不会用通用教程内容填满。

## 重点判断方法

- **新链接先买什么流量**：直冲大词、小词带大词、自动和商品投放拓量三条路的区分条件；预算、转化率、词根共享度怎样决定取舍；撞到瓶颈期怎样转入维持。
- **单量异动诊断**：先看整体再拆小时；自然单波动和广告单波动的分叉排查顺序；CPC 与 CVR 的进一步二分；归因窗口内不下结论。
- **广告异常排查**：没曝光、有点击没出单、ACOS 偏高、自动转手动落差等形态各自指向的排查方向；为什么测试要用固定竞价才准。
- **竞价与广告位控制权**：固定竞价、只降低、提高和降低、基于规则各自适用什么阶段；哪些场景该把控制权留在自己手里；后台建议竞价为什么只能当参考。
- **关键词投放与 ASIN 投放的取舍**：「要词」本质是要词下的曝光点击加购购买四个动作；ASIN 定投的进攻（截流弱于自己的竞品）、防守（自家产品护城河）、加权（借商品页反查词）三种用法。
- **品类形态决定打法**：标品、半标、非标的流量词集中度差异；竞价其实是跟竞争对手竞价而非跟平台；无低价无品牌硬挤红海集中词为什么难做。
- **断货与数据卫生**：好链接怕的不是断货而是断货前的垃圾数据；强季节品计划内断货与正常品被动断货的不同处理。

## 材料范围与边界

学习范围是这批转写中的运营判断与打法经验。以下内容会识别后排除或收窄：线下活动宣传、拍摄花絮、训练营招生等非知识内容；纯工具按钮操作演示（只保留其背后的判断意图）；与其他篇目重复录制的版本由系统在完整阅读后择优合并，不会重复成多章。

老师的平台数字（加价比例上限、竞价区间、Vine 规则等）会带时效条件保留，标注为当时的平台状态；缺少数据反馈的经验断语保留原话并注明「材料未提供反馈」。材料基本不覆盖利润核算细节、站外流量配合、SB/SBV/DSP 广告体系，这些缺口会在成品中如实说明，不用通用内容补齐。

## 完成后能解决的问题

读者（或接入专家 Skill 的智能体）将能处理：新品期预算有限时选推广路径；日常复盘时按顺序定位单量波动原因；广告表现恶化时逐层排除原因而不是凭感觉调价；根据自己产品的品类形态设定合理的竞价预期和打法；断货前后保护链接数据；判断一个流行打法（低价螺旋、卡 Top 位、阶梯优惠券）适不适合自己的品。

老师解决不了、成品也不会假装能解决的：替你核算具体利润结构、预测平台下一次规则改动、为没有数据反馈的断言提供证明。
