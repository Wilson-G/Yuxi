# 制造专家 Agent

知铸把文章、课程、讲义、案例和企业经验制造成能够实际回答问题的专家 Agent。

普通知识库让智能体找到相关内容；知铸继续学习材料中的方法、判断条件和实践边界。专家不仅知道“材料里有什么”，还应该知道“面对这个问题先看什么、怎样判断、为什么这样判断”。

## 哪些材料适合

适合的材料通常包含稳定的专业经验或判断方法，例如：

- 一位老师的系列课程、文章、讲义和案例解析；
- 企业内部的操作手册、项目复盘、决策记录与资深员工经验；
- 某个技术方向的标准、设计文档、故障案例和最佳实践；
- 行业研究、咨询方法、访谈记录和长期积累的专题资料；
- 多位专家针对同一领域的观点、分歧与适用条件。

只有零散事实、重复资讯或缺少可靠来源的材料，更适合放入普通知识库，不一定值得制造一个专家 Agent。

## 1. 在资料库准备材料

管理员进入「专家 · 技能」中的「资料库」：

1. 创建资料库和需要的目录。
2. 批量上传文件，或直接选择包含多份文件的目录。
3. 查看每份文件的处理进度、失败原因和规范化正文。
4. 对失败文件单独重试，不影响已经完成的其他文件。
5. 核对系统形成的自然主题材料单元及其来源行范围。

资料库是新增专家材料的唯一入口。原始文件、规范化正文和解析图片只保存一份；专家项目只建立材料单元关联，不复制正文。

只有单元状态已经就绪的材料才能用于新项目。长材料无法形成完整自然单元时会进入“需要处理”，不会按固定字符数截取一段继续学习。

## 2. 创建专家项目

进入「专家项目」，填写项目名称、说明和模型，选择教材笔记法或领域推导资产法，再选择资料库中的就绪材料单元。方法选择会在项目创建时固定；同一批材料可以分别创建两个独立项目进行比较。项目创建后：

- 不再次上传、OCR 或解析来源文件；
- 从资料库读取同一份规范化正文；
- 被引用的来源文件和材料单元不能覆盖或删除；
- 已经直接上传材料的旧项目继续按原记录兼容读取，但不能新增或替换材料。

专家训练只允许管理员推进。普通用户只能使用已经启用并通过 `share_config` 分发的专家 Skill。

## 3. 确认学习方向

从项目材料中选择最多 20 份、尽量覆盖不同方向的代表材料。系统会完整阅读这些材料，形成当前项目的学习方案和真实笔记小样。

这里需要确认的是：这个专家应该从材料中学习什么、重点关注哪些判断方法，以及材料边界是否合适。方向不对时提交反馈重新生成；确认后系统才开始逐份学习全部材料。

## 4. 处理材料问题

系统以一个自然材料单元为一份独立学习工作。单份失败不会重跑已经完成的其他材料。

材料进入“需要处理”时，可以：

- 根据错误原因重跑当前材料；
- 明确排除本轮不采用的材料；
- 暂停整个项目，之后从持久化进度恢复。

系统不会在用户未处理时越过问题进入下一阶段。

## 5. 确认知识组织方式

材料学习完成后，页面展示知识组织方案和少量讲义小样。这里需要确认的是：读者应该从哪些问题进入、主题边界是否合理，以及表达方式是否符合最终专家。

未经确认，系统不会批量形成完整讲义。需要调整时提交反馈，系统创建新的组织版本并重新生成小样。

## 6. 预览、启用和分发

成品预览包括专家说明、使用导航、正式讲义、精选证据、来源映射和未纳入材料。确认可用后手动启用专家 Skill。

启用后可以沿用现有 Skill 共享权限分发给普通用户。卸载 Skill 会保留专家项目和候选成品，之后可以再次启用。删除项目不会删除资料库材料；已启用的项目必须先卸载 Skill，运行中的项目必须先暂停。

## 怎样验收一个专家

不要只问它能否复述材料。更有价值的检查方式是：

- 给出具体案例，看它是否先识别关键信号再下结论；
- 改变一个重要条件，看它是否会相应改变判断；
- 提供信息不足的问题，看它是否知道继续追问或明确停下；
- 询问冲突观点，看它是否保留各自前提而不是强行合并；
- 追问“为什么”，看它能否解释判断路径并给出材料依据。

一个合格的专家 Agent 应该有方法、有条件意识、有证据，也知道自己的边界。
